# tools/

Lege hier das **MPC Autofill Desktop-Tool** ab (z. B. `autofill-windows.exe`), dann findet der
Deckbuilder es automatisch. Download: https://github.com/chilli-axe/mpc-autofill/releases

Alternativ den Pfad in der GUI unter „Proxy-Einstellungen“ oder per `MTG_AUTOFILL_PATH` setzen.
Dateien in diesem Ordner werden nicht ins Git-Repo übernommen.
