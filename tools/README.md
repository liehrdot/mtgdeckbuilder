# tools/

Externe Programme für den Proxy-Druck. Dateien in diesem Ordner werden nicht ins Git-Repo übernommen;
der Deckbuilder findet sie hier automatisch (alternativ Pfade in der GUI unter „Einstellungen“).

- **MPC Autofill** (Upload zu MakePlayingCards): z. B. `autofill-windows.exe` direkt hier ablegen.
  Download: https://github.com/chilli-axe/mpc-autofill/releases
- **Real-ESRGAN** (optionale KI-Hochskalierung, Opt-in): `realesrgan-ncnn-vulkan` für dein System
  herunterladen und z. B. nach `tools/realesrgan/` entpacken – der Ordner `models/` muss neben der
  exe liegen. Download: https://github.com/xinntao/Real-ESRGAN/releases
