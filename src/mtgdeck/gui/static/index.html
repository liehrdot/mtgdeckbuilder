    So funktioniert's

    1. Commander eingeben (Autovervollständigung über Scryfall) und Bracket wählen.
    2. „Deck bauen lassen“ startet Claude Code mit dem Skill commander-deckbuilder. Claude recherchiert über den MCP-Server auf Scryfall, EDHREC und Commander Spellbook.
    3. Das fertige Deck wird geprüft (Legalität, Farbidentität, Bracket-Regeln) und in decks/ gespeichert.
    4. Mit „Überarbeiten lassen“ kannst du Änderungen in natürlicher Sprache anfordern.
