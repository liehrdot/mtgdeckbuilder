      So funktioniert's

      1. Commander eingeben (Autovervollständigung über Scryfall) – oder unter „Keine Idee? Commander finden“ beschreiben, was du spielen willst, und dir Vorschläge machen lassen.
      2. Bracket wählen, Budget setzen oder „Proxy-Deck“ aktivieren, wenn du das Deck proxen willst.
      3. „Deck bauen lassen“ startet Claude Code mit dem Skill commander-deckbuilder. Claude recherchiert über den MCP-Server auf Scryfall, EDHREC und Commander Spellbook.
      4. Das fertige Deck wird geprüft (Legalität, Farbidentität, Bracket-Regeln, Budget, deine Blacklist) und in decks/ gespeichert.
      5. Mit „Überarbeiten lassen“ kannst du Änderungen in natürlicher Sprache anfordern.
